# 教材PDFの更新と検証

本文は「科目B_擬似言語とAIで学ぶアルゴリズム入門.md」、追加演習・全解説・図の処理定義は `exercises.mjs` で管理します。Markdown内の「追加演習開始〜終了」と各問の「解答・解説」は生成対象です。そこを修正する場合は `exercises.mjs` を変更してください。「解答・解説」の冒頭に置く共通の読み方はMarkdownで編集し、再生成でも維持されます。既存11問の問題文を変えた場合も、対応する処理定義と期待値を更新します。表示を求める問題は、期待値の `$output`（文字の配置は `$text`）で表示内容と順番も検査します。

各問の `solution` は解答欄の順に並べた解答値、`answer` は理由や考え方を説明する解説です。項目名は問題側の解答欄から再使用し、項目数の一致を検査します。記入用の表がある7-B・7-D・8-Cの完成表は解答側、それ以外の確認表は解説側へ配置します。全48問の解答・解説の区分と、解答表100項目を検査します。

本文の章は `#`、学習テーマと独立した演習は `##`、その中の構文の種類や活用例は `###`、さらに下位の比較や説明例は `####` とします。節番号は学習テーマの `##` に付け、章内で連番にします。見出しの階層を飛ばさず、例や補足をどの説明の下に置くかも確認してください。第5章の①初期化・②継続条件・③更新は、コードと表で番号と色を対応させています。回数の説明は、1〜5と0〜4の具体例で行います。

番号付きの学習テーマの下では、ビルド時に `###` を5.3.1のような三段の番号、`####` を5.2.1.1のような四段の番号へそろえます。再ビルドでも番号は重複しません。本文の小見出しには背景色と左の線、さらに下位の見出しには下線を付け、印刷時は次の内容との間に6mmの余白を設けます。演習の「解答」「解説」には節番号を追加しません。

繰返しの図は、同じ名前を持つ上下のループ端で処理の範囲を囲みます。forの開始側には初期値・終値・増分、whileの開始側には継続条件を記載し、ひし形はifの分岐に使います。生成SVGの上下の枠はそれぞれ上側・下側の角を切った六頂点の多角形とし、全演習でループ端の組数を検査します。二重ループの本文はiを青、jを赤とし、コード・表示結果・表・説明で対応させます。5-Bの解説の確認表は○・×・―を使い、実行履歴から各回の記号を照合します。問題側では表への記入を求めません。

説明用コードの直前には `example-task` で課題を明記し、コードと一緒に `code-example` へ入れます。表示命令がある例には、直後へ `display-result` の別枠を付け、入力や条件で結果が変わる場合は値を明記します。表示しない操作の断片には、目的と必要な実行前の値を記載します。演習の短い課題文は `exercises.mjs` の `codeTask` で管理し、問題のコードの直前へ生成します。演習の表示結果は問題側で先出しせず、解答・解説側へ実行結果から生成します。5-A・6-C・8-Aは確認表の横へ配置します。4-B・4-Cは設問で指定された各境界値の表示も示し、確認表ではどの入力の場合かを見出しに明記します。8-Cの問題側の表示例は、作る形を指定するための例として維持します。

第1章は★3問・★★3問の記述式、第2章は各難易度2問の記述式です。第4章は★2問・★★3問・★★★1問で、第3章と第5〜8章は各難易度2問です。第3〜8章の選択式全12問（演習4-Eは★★、ほか11問は★★★）の選択肢と正解記号は `exercises.mjs` の `choices` で管理します。演習8-B・8-Cの「選択肢開始〜終了」も生成対象です。ビルド時に各問4択・重複なし・正解記号を検査し、HTMLの選択肢48件とPDFの正解記号12件を確認します。選択肢の同ページ検査は難易度ではなく、選択式の問題番号で行います。数値を扱う全42演習は `types` に使う変数をすべて宣言し、コード枠内の先頭へ掲載します。本文29例も宣言を省略しません。同じ型の複数変数は、本文2.2で説明するカンマ区切りも使います。整数・実数・文字列などの型、配列、繰返し変数、入力済みの変数も確認します。配列の宣言に初期値を含める場合は、検算用の入力配列と一致させます。

ビルド時は全71コードの使用名と宣言、演習の掲載コードと `types` の宣言の一致、全検算ケースの入力・処理途中・最終値と宣言した型の一致を検査します。条件式や選択肢の空欄に隠れている変数も、正解の処理定義から照合します。既存11問のコードはMarkdownで管理し、宣言も原稿で修正します。ほかの31問は `types` から宣言を含むコードを生成します。

全48問のAIへの質問例も `exercises.mjs` の `aiQuestion` で管理します。問題番号の文と空行に続けて、「分かっていること・試したこと・分からないこと」を改行で区切って記載し、第0章と同じ形式で表示します。既存問題の質問例もビルド時に本文へ反映します。問題の表と同じ形式の完成例が必要な場合は `answerTable` に見出しと全行を記入し、値と真偽を本文のコードで照合してください。長いトレースも中間の反復を省略しません。

第1〜6章では、演習の解答を値・表示順・回数・空欄・選択肢などの通常の解答欄へ書き、表への記入を求めません。本文の対応表や解説の確認表は、動きを示す説明として使います。表の作り方と値を記録する技術は第7章で導入します。第6章の6問はすべて `exercises.mjs` から生成し、添字と値・要素の表示・合計・最大値・料金の集計・最初の位置の探索の順に配置します。

条件分岐の7-Bと二重繰返しの8-Cは、`tracePractice` に記入案内と完成表を定義し、同じ列名・行ラベルから空欄の表を生成します。完成表13行は、実際の処理履歴・表示結果と照合します。記入表はコード直後へ配置し、7-Bは解答欄、8-Cは選択肢より前に置きます。既存問題の表は「トレース表開始〜終了」が生成対象です。8-Cはコードと9行の記入表を同じページ、出力例・選択肢・解答欄・AI質問例を直後の続きページへ配置します。解説文・AI例文・入力値は元の問題定義へ記載し、後から別の定義で上書きしません。第6章までに記入表がないこと、全48問の解説文、2問の表の列名・行数、コードとの同ページ配置、8-Cの続きページの連続配置を検査します。第7章の6問はすべて生成対象で、実行前後・条件分岐の表・誤りの発見・繰返しの表・境界の検証・連続した記録の順です。7-Cの受講者の誤った表は `questionTable` で問題側にだけ掲載し、解説の正しい確認表は処理の実行結果から生成します。

第8章の確認欄は章の冒頭へ一つだけ置かず、全6問の問題文の後・コードの前へ配置します。各問の `prechecks` に3項目の確認内容を定義し、チェック欄を生成します。既存8-A〜8-Cは「確認欄開始〜終了」が生成対象です。6欄すべてが対応する問題内にあること、確認項目の一致、コードより前にあることをビルドで検査し、PDFでも各問題との同ページ配置を確認します。8-Bの従来の「考えるポイント」は確認欄へまとめ、重複させません。

表紙・研修の目標・研修の概要・この教材の使い方は、原稿冒頭の4ページです。目標と概要は、オレンジ色の罫線を持つスライド風の枠と、その下の補足説明を組み合わせます。概要の第0〜8章の一覧は、本文の章題から生成するため、原稿の `.course-chapter-list` へ直接書き込みません。

章開き・目次・索引は `book-navigation.mjs` で生成します。第0〜8章の章開きには章番号・章題・3項目の目標を載せ、本文は次のページから始めます。章開きはPDFの物理ページ番号で偶数に統一し、必要な場合だけ直前に「（空白ページ）」を挿入します。表紙を1ページ目として数え、本文の下端に載るページ番号と合わせます。フッターは `教材.css` の `@page` で出力し、表紙・章開き・奥付では非表示にします。それらのページもページ数には含めます。

目次は5〜7ページの3枚・96項目で、目標・概要・使い方、章・節・小見出し、各章の演習、解答・解説、巻末資料・奥付を案内します。索引67項目と参照先は `book-index.mjs` で管理します。節の参照IDは `section-6-3-2`、演習は `question-8-B` の形式です。索引は用語の説明箇所を参照し、同じ用語の参照先が同一ページになる場合はページ番号の重複を省きます。目次と索引はPDF内でクリックできます。

奥付は原稿末尾の `.colophon` で管理し、生成する索引をその直前へ配置します。発行日は「2026年10月19日　第1版　発行」で固定し、再ビルドの日付に置き換えません。コースコードは記載しません。奥付を最終の奇数ページにするため、必要な場合だけ直前へ空白ページを追加します。

`pdf-page-map.py` がPDFのリンク先から実ページ番号を取得します。ビルド内で、章開きと奥付の偶奇、空白ページ、目次・索引のページ番号が変わらなくなるまで再組版し、`tmp/pdfs/navigation.json` に結果を保存します。古い `toc.json` を参照して目次のページを埋める作業は不要です。検査では、PDFに印刷された全参照数字と実際のリンク先、冒頭4ページの内容、章扉と本文の分離、奥付が最終の奇数ページであること、不要な白紙がないことも確認します。

必要なものはNode.js、marked、playwright、@viz-js/viz、Chrome、Python（pypdf・pdfplumber・Pillow）、Popplerです。

1. 環境変数 `FE_NODE_MODULES` に上記Nodeパッケージのある `node_modules` の絶対パスを設定します。Chromeが標準の場所にない場合は `FE_CHROME` に実行ファイルを指定します。PythonがPATH上にない場合は `FE_PYTHON` にPythonの実行ファイルを指定します。
2. `node 教材/build.mjs` を実行します。48問の構成と計算・境界条件を検査し、図・本文生成部分・`tmp/pdfs/textbook.pdf` を更新します。
3. `python 教材/check-pdf.py --render ＜pdftoppm.exeの絶対パス＞` を実行します。PDFの問題とAI質問例（8-Cだけは直後の続きページ）、全48解説と図がそれぞれ同じページにあること、HTMLタグ漏れ、章の実ページを検査し、確認画像と `toc.json` を作ります。
4. 検査結果の章開き・空白ページ・目次・索引の参照数を確認します。ページ番号はビルド内で確定するため、反映のための再ビルドは不要です。
5. 全ページの一覧画像と、図・表を含むページの拡大画像で、文字の欠け、改ページ、矢印の分岐と戻り先を確認します。検算器の成功だけではレイアウトを保証しません。
6. 確認したPDFを `output/pdf/科目B_擬似言語とAIで学ぶアルゴリズム入門.pdf` にコピーします。開いているPDFによって上書きが失敗したら、成功したと扱わず、ファイルを閉じて再実行します。

生成結果は原本へ直接書き込むため、実行前にGitの差分を確認してください。公開問題への参照と研修用オリジナル問題の区別を維持し、共有ノートブックでの動作は[講師向けの準備手順](講師向け_AI学習支援の準備.md)に沿って別途確認します。
