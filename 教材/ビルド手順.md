# 教材PDFの更新と検証

本文は「科目B_擬似言語とAIで学ぶアルゴリズム入門.md」、追加演習・全解説・図の処理定義は `exercises.mjs` で管理します。Markdown内の「追加演習開始〜終了」と各問の「解答・解説」は生成対象です。そこを修正する場合は `exercises.mjs` を変更してください。「解答・解説」の冒頭に置く共通の読み方はMarkdownで編集し、再生成でも維持されます。既存14問の問題文を変えた場合も、対応する処理定義と期待値を更新します。表示を求める問題は、期待値の `$output`（文字の配置は `$text`）で表示内容と順番も検査します。

各問の `solution` は解答欄の順に並べた解答値、`answer` は理由や考え方を説明する解説です。項目名は問題側の解答欄から再使用し、項目数の一致を検査します。2-C・5-B・6-B・7-Dの完成表は解答側、それ以外の確認表は解説側へ配置します。全48問の解答・解説の区分と、解答表100項目を検査します。

本文の章は `#`、学習テーマと独立した演習は `##`、その中の構文の種類や活用例は `###`、さらに下位の比較や説明例は `####` とします。節番号は学習テーマの `##` に付け、章内で連番にします。見出しの階層を飛ばさず、例や補足をどの説明の下に置くかも確認してください。第5章の①初期化・②継続条件・③更新は、コードと表で番号と色を対応させています。回数の説明は、1〜5と0〜4の具体例で行います。

説明用コードの直前には `example-task` で課題を明記し、コードと一緒に `code-example` へ入れます。表示命令がある例には、直後へ `display-result` の別枠を付け、入力や条件で結果が変わる場合は値を明記します。表示しない操作の断片には、目的と必要な実行前の値を記載します。演習の短い課題文は `exercises.mjs` の `codeTask` で管理し、問題のコードの直前へ生成します。演習の表示結果は問題側で先出しせず、解答・解説側へ実行結果から生成します。5-A・6-A・8-Aは確認表の横へ配置します。4-B・4-Cは設問で指定された各境界値の表示も示し、確認表ではどの入力の場合かを見出しに明記します。8-Cの問題側の表示例は、作る形を指定するための例として維持します。

第1章は★3問・★★3問の記述式、第2章は各難易度2問の記述式です。第4章は★2問・★★3問・★★★1問で、第3章と第5〜8章は各難易度2問です。第3〜8章の選択式全12問（演習4-Eは★★、ほか11問は★★★）の選択肢と正解記号は `exercises.mjs` の `choices` で管理します。演習8-B・8-Cの「選択肢開始〜終了」も生成対象です。ビルド時に各問4択・重複なし・正解記号を検査し、HTMLの選択肢48件とPDFの正解記号12件を確認します。選択肢の同ページ検査は難易度ではなく、選択式の問題番号で行います。演習4-Dの型の宣言は擬似言語の枠内に配置します。

全48問のAIへの質問例も `exercises.mjs` の `aiQuestion` で管理します。問題番号の文と空行に続けて、「分かっていること・試したこと・分からないこと」を改行で区切って記載し、第0章と同じ形式で表示します。既存問題の質問例もビルド時に本文へ反映します。問題の表と同じ形式の完成例が必要な場合は `answerTable` に見出しと全行を記入し、値と真偽を本文のコードで照合してください。長いトレースも中間の反復を省略しません。

第6章全6問と二重繰返しの8-Cは、`tracePractice` に記入用の案内と完成表を定義し、同じ列名・行ラベルから空欄の表を生成します。完成表46行はビルド時に実際の処理履歴・表示結果と照合します。6-A・6-E・6-F・8-Cは `worksheet: true` とし、問題の直後に記入用ページを配置します。6-B・6-C・6-Dの表は問題ページ内に置きます。既存問題の表・用紙は「トレース表開始〜終了」「トレース用紙開始〜終了」が生成対象です。解説文・AI例文・入力値は元の問題定義へ記載し、後から別の定義で上書きしません。全48問の解説文が空でないこと、全7問の表の列名・行数、問題と用紙の連続した配置も検査します。

必要なものはNode.js、marked、playwright、@viz-js/viz、Chrome、Python（pypdf・Pillow）、Popplerです。

1. 環境変数 `FE_NODE_MODULES` に上記Nodeパッケージのある `node_modules` の絶対パスを設定します。Chromeが標準の場所にない場合は `FE_CHROME` に実行ファイルを指定します。
2. `node 教材/build.mjs` を実行します。48問の構成と計算・境界条件を検査し、図・本文生成部分・`tmp/pdfs/textbook.pdf` を更新します。
3. `python 教材/check-pdf.py --render ＜pdftoppm.exeの絶対パス＞` を実行します。PDFの全48問とAI質問例、全48解説と図がそれぞれ同じページにあること、HTMLタグ漏れ、章の実ページを検査し、確認画像と `toc.json` を作ります。
4. もう一度ビルドします。実ページ番号が目次へ反映されます。再検査でページ位置が同じか確認してください。
5. 全ページの一覧画像と、図・表を含むページの拡大画像で、文字の欠け、改ページ、矢印の分岐と戻り先を確認します。検算器の成功だけではレイアウトを保証しません。
6. 確認したPDFを `output/pdf/科目B_擬似言語とAIで学ぶアルゴリズム入門.pdf` にコピーします。開いているPDFによって上書きが失敗したら、成功したと扱わず、ファイルを閉じて再実行します。

生成結果は原本へ直接書き込むため、実行前にGitの差分を確認してください。公開問題への参照と研修用オリジナル問題の区別を維持し、共有ノートブックでの動作は[講師向けの準備手順](講師向け_AI学習支援の準備.md)に沿って別途確認します。
